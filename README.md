# 搬家甩卖页面

这个仓库就是线上那个页面本身。push 一次 = 自动部署一次。

```
index.html      整个页面（38 KB，照片不再内嵌）
photos/         31 张照片，文件名就是商品 id：i1.jpg … i31.jpg
netlify.toml    告诉 Netlify 直接发布根目录，没有构建步骤
```

库存状态不在这里，在 Google 表格里。页面每次打开、每次从别的标签页切回来，都会重新拉一遍表格。

---

## 加一件新东西

三步，顺序无所谓：

1. **传照片** — 把照片放进 `photos/`，命名成 `i32.jpg`（下一个没被占用的 id）。
   照片不用压，原图直接传，Netlify 会现场压成 webp 再发给访客。
   手机上也能做：github.com 上进 `photos/` → Add file → Upload files。
2. **加一行** — Google 表格最下面加一行，`id` 填 `i32`，填 `name` / `price` / `total` / `category`。
   `sold` 记得勾成复选框（选中这一格 → 插入 → 复选框）。
3. 等 Netlify 部署完（约 1 分钟）+ 表格缓存过期（约 5 分钟），刷新页面。

**照片和表格谁先谁后都行。** 只加了表格行还没传照片，那张卡片会显示「暂无实拍」，不会报错也不会崩。

## 日常操作

| 想干什么 | 怎么做 |
|---|---|
| 卖掉一件 | 表格里勾上 `sold`，页面上盖「已出」章，卡片沉到最底 |
| 标记上新 | 勾上 `new`，卡片浮到最前、左上角加绿色「上新」角标，文字清单里前缀「【上新】」 |
| 多件的卖掉一部分 | 改 `remaining`（椅子 6 把卖了 2 把就填 4） |
| 改价格 | 改 `price`；留空显示「价格面议」 |
| 补一句说明 | `note` 填「有个小划痕」，显示在价格下方 |
| 照片方向不对 | `rotate` 填 90 / 180 / 270 |
| 照片想裁满整个框 | `fit` 填 `cover`（默认是完整显示不裁） |
| 换一张照片 | 覆盖 `photos/iN.jpg` 同名文件，push |
| 照片不叫 id 的名字 | `img` 列填文件名（如 `chair-2.jpg`），或整条外链 URL |
| 标注入手年份 | `year` 列填 `2024`，卡片显示「2024 年入手」 |

`year`、`img`、`fit` 这三列**可以不建**。不建的时候：`img` 按 id 推导文件名，`year` 用页面里烘焙的快照，`fit` 默认完整显示。建了就以表格为准。

**卡片顺序**是自动的：上新 → 在售 → 已出，每组内部保持表格里的行序。所以想调整某件东西的位置，改它在表格里的行位置就行。一件东西同时勾了 `new` 和 `sold` 时按已出处理——沉到底、不显示上新角标。

**发微信群**：页面上点「复制文字清单」→ 粘到群里。自动按分类排好，带价格、自提配送、页面链接，已出的自动不列。

**发小红书**：点「截图模式」→ 按钮全部隐藏、两列紧凑排版、俏皮话变成正文、底部带微信号 → 截图。会先把所有图片加载完再提示「可以截图」，别抢在提示之前截。

## 照片是怎么送到访客手上的

页面不直接引用 `photos/i1.jpg`，而是走 Netlify 自带的图片处理接口：

```
/.netlify/images?url=%2Fphotos%2Fi1.jpg&w=800&fm=webp
```

同站图片不需要任何配置，开箱就能用。所以：

- **传原图就行**，不用自己压尺寸。
- 卡片按 400 / 800 / 1200 三档出 `srcset`，手机自动挑小的。
- 卡片背景那层反正要模糊 16px，只取 96 宽——单张从 156 KB 降到 1.7 KB。

万一这个接口出问题，页面会自动退回直接读 `photos/i1.jpg`；再不行才显示「暂无实拍」。本地双击打开 `index.html` 时会自动跳过这个接口，所以本地预览也是正常的。

## 注意事项

- **Netlify 免费额度**：新的 credit 计划是每月 300 credits，每次生产部署扣 15，也就是**每月约 20 次 push**。攒着一次推比推 5 次划算。（账号如果是 2025-09-04 之前注册的，是老计划，按流量算，没有这个限制。）
- **别把地址、电话、账号写进 Google 表格。** 那张表是公开只读发布出去的。
- 改了表格页面没变？等 5 分钟——Google 的发布端点有约 5 分钟缓存——然后点页面上的「刷新」。
